# Pharmacy Management System

A desktop app for the day to day work of a pharmacy, built in Java with JavaFX.

It covers login, adding drugs and companies, recording purchases, managing users, and viewing stock.

## Screens

- `Main.java`, `HomePage.java`, `Login.java` - app entry and main screens
- `add_drugs.java`, `add_company.java`, `new_purchase.java`, `add_user.java`, `Show.java` - the working screens
- `Pharmacy-Management-System_Project Report.pdf` - the project report

## Running

Open the project in an IDE with JavaFX set up (Eclipse or IntelliJ) and run `Main.java`.
